# Book & Stationery Online Shopping System

## Project Overview

This is a web-based Book & Stationery Online Shopping System developed as a university assignment. The system provides an online shopping experience for browsing products and managing shopping activities.

The project was developed to apply web development and database management concepts in a practical application.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL / MariaDB
- XAMPP

## Main Features

- **User Management:** User registration, login, and account-related functions.
- **Product Management:** Product and category management.
- **Shopping Cart:** Functions for managing selected products.
- **Order Management:** Functions for handling customer orders.
- **Administration:** Administrative functions for managing the store.
- **Simulated Payment:** A mock payment process for academic demonstration purposes. No real banking transactions are processed.

*Note: The features listed above should be adjusted to match the functions actually implemented in the project.*

## Project Structure

The repository is organised into folders for different parts of the system, including:

- `admin` — administrative functions
- `cart` — shopping cart functions
- `config` — application configuration
- `includes` — reusable application components
- `member` — member-related functions
- `order` — order-related functions
- `product` — product-related functions

## Running the Project

This project was developed for a local XAMPP environment.

1. Install and start Apache and MySQL using XAMPP.
2. Place the project folder in the XAMPP `htdocs` directory.
3. Create the required database in phpMyAdmin.
4. Import the sanitised sample SQL file.
5. Configure the database connection using your local settings.
6. Open the project through your local web server.

Database credentials and other sensitive information should not be committed to the repository.

## Project Purpose

This project provided practical experience in web application development, PHP programming, database integration, and implementing common online shopping functions.

## Payment Disclaimer

The payment functionality is simulated for educational purposes only. The application does not process real payments or connect to a real banking system.
